# NordVPN

These scripts are meant to easily set up NordVPN as a peer or an  
exit node.

The following commands are supplied:

- login.sh
- logout.sh
- config.sh
- connect.sh
- list_connected
- exit-node.sh
- status.sh


## Peer names

mesh-hp

mesh-tab8

mesh-raspberry
